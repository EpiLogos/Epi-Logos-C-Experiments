# Coordinate Gap Matrix

## Reading The Matrix

- **Composition** means the capability exists but is arranged poorly.
- **Integration** means the service or component exists but is not made reliably product-live.
- **Substrate** means the required method, projection, governed route, or body is absent or unverified.
- Severity is based on user impact and whether the defect prevents the canonical work loop.

## Critical Chain

The shortest path to a credible product is:

```text
truthful native startup
-> stable workbench shell
-> first-class work context
-> complete [[M5']] agent/change/review loop
-> coordinate workspace presets
-> broader [[S]]/[[S']] capability completion
```

Visual polish before the first four links would make the current fragmentation more attractive without making it more usable.
