# 53.T53.08 — Tail residency audit

**Date:** 2026-07-28 · **Tranche:** `53.T53.08` — *The remaining tail: agent, bimba, portal, nara, tui*

The tranche asks for a per-site record of which resolution each remaining `epi-cli` → S-crate
reference took, "because this is the tail where 'it was easier' silently becomes the next
allowlist." This is that record.

## The resolutions available

The brief names three. The Architect ruling of 2026-07-28 (`S0-membrane`, see `53.T53.02`) adds a
fourth, and it is the one most of the tail legitimately takes:

| | Resolution | When it applies |
|---|---|---|
| (a) | The shared **type moves down** to `epi-kernel-contract` | Both sides need to name it and neither may import the other |
| (b) | The **caller moves** to its coordinate | The call site holds that coordinate's law |
| (c) | The call goes **through the registry** | It is a gateway method |
| (d) | **CLI passthrough — stays** | The site only lets a human reach the module from the terminal. This is the membrane's function, not debt. |

(d) is not an escape hatch. It is checkable, and this tranche made it so — see *Enforcement* below.

## Enforcement — why (d) is not the next allowlist

Recording "it's passthrough" is worth nothing if nothing checks it. Two guards now do, and neither
covered this tail before today:

1. **The residency ratchet was widened from `gate/` + `graph/` to the whole crate**
   (`contracts/s0-membrane-residency.json`). It counts files naming an S1/S2/S3/S5 crate and fails
   when the count rises. `agent/`, `nara/`, `portal/`, `tui/` and `bimba.rs` were previously
   unmeasured — a handler added under `agent/` would have raised no alarm anywhere. Ceiling:
   **77 files / 22,287 code lines**, and it may only fall. Proven by injection: a law-bearing file
   dropped under `src/agent/` exits 1 naming it; removed, exits 0.
2. **The categorical guard** (`tests/s0_membrane_guardrails.rs`) already required every module in
   its law zones — `gate/`, `graph/`, `vault/`, `core/` — to be inventoried or to carry an
   `// S0 ADAPTER: Body/S/<…>` header naming its authority. `vault/frontmatter.rs`, `vault/mod.rs`
   and `core/knowing/` are all inventoried.

The ratchet was chosen over widening the categorical guard's zones deliberately: the guard flags
*any* unlisted module in a zone, so adding `agent/` would have flagged dozens of files that
reference nothing. The ratchet flags exactly the law-bearing ones.

## What this does not claim

The tail is passthrough **today**. That is a measured statement about the current tree, not a
permanent property — which is the whole reason the ratchet now covers it.
