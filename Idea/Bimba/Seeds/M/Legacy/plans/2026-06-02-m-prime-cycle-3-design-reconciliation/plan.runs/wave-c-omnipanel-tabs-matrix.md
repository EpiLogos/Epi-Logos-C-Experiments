## Standing-Invariant Honouring

- **15.2 reframe canon.** OmniPanel is the agentic-membrane housing repurposed ACR substrate. `run-model.ts` → `omnipanel-runtime.ts`. ACR widgets → OmniPanel tabs (Pi Chat, Sessions, Dispatch Trace, Tool Stream, Evidence, Review, Gateway, Diagnostics). **No new ACR-style extension; consume the substrate as the OmniPanel content model.**
- **DR-M5-1.** Pi (single harness, agentic conversational membrane) + Anima (main dispatcher; orchestrates from S4') + six Aletheia subagent techne-guardians (Anansi/Janus/Moirai/Mercurius/Agora/Zeithoven) dispatched during Aletheia-crystallisation-mode. NOT seven peer agents. Pi Chat = Pi-as-conversational-membrane. Anima is invoked BY Pi (not user-direct). Aletheia subagents appear in Dispatch Trace as sub-traces under Anima's `aletheia-crystallisation` dispatch envelope.
- **DR-TS-1.** State (`coordinate`, `lens`, `mode`, `profileGeneration`, `sessionKey`, `dayNow`) survives `daily-0-1` ↔ `ide-deep` toggle. Add: **active OmniPanel tab** + **per-tab local state** also survives. Per layout-types.ts L7-12.
- **DR-TS-4.** Six operational-capacity views are M5'-chrome (lives in `m5-epii` standalone widget per stage-1 Tranche 26.2), NOT new OmniPanel tabs. OmniPanel exposes EXACTLY 8 tabs (Pi Chat, Sessions, Dispatch Trace, Tool Stream, Evidence, Review, Gateway, Diagnostics). No more, no less.
- **15.2 no-modal invariant.** Review tab IS the landing surface. NEVER a modal dialog. Same for Evidence (per stage-1 Tranche 26.4 cross-link).
- **DR-MP-1 (mental-pole triplet).** OmniPanel Pi Chat = M4' LLM voice (Pi-as-membrane); M5' standalone widget = M5' EBM observatory; M0' Verifier surfaces only in WisdomDeltaInspector close-path. Pi Chat is NOT the EBM. Pi Chat is NOT meta-conversation. Pi Chat is the conversational front (the "voice" of recognition).
- **DR-B-2.** Pi tool-surface (axiom-translation) is visible from Pi Chat as slash-command grammar (`/translate philosophical-english → owl ...`); inspector lives in `PiAxiomTranslationInspector` (stage-1 Tranche 26.14) cross-linked from Dispatch Trace.
- **DR-B-3.** Aletheia subagents are NOT in the user's direct invocation surface (no `/dispatch anansi` at top level — they only surface BY Anima during crystallisation-mode). Slash-command grammar at Pi Chat allows `/aletheia crystallise <intent>` which dispatches Anima → Aletheia-crystallisation-mode → subagent fan-out; the resulting Dispatch Trace shows the sub-trees.
- **Privacy class flow-through.** Every tab that may render M4-protected-local content (Sessions session metadata, Evidence packets touching Nara, Review of M4 candidates) renders `privacyClass` indicator. M4-protected never crosses the public bridge — Evidence packets containing Graphiti protected handles render handle metadata only, never body.
- **Profile-tick is the clock (15.6).** Every tab subscribes to `subscribeToProfileTick`; UI advances on tick advance, not user input. Readiness state renders inline per data binding — no separate "errors" panel.
- **SharedBridgeAdapter is the only seam.** No tab directly imports S0/S2/S3/S5 clients, raw WebSocket, raw Neo4j driver, raw SpacetimeDB SDK, `epii-review-core`, `epii-agent-core`. All gateway access through `KERNEL_BRIDGE_API.invokeGatewayRpc` (per 07-t0 contract).
- **Forbidden-direct-import lint (11.5).** Extended to OmniPanel tab implementation modules.
- **Anima/Epii split (MEMORY).** Pi Chat is conversational membrane (S4' surface). When user requests deep knowledge, Pi invokes Epii (S5') and renders Epii's reading inline. Sessions tab maps to `agent:epii:main` + siblings — Epii's main session is the user's anchor session.

## Closing

The substrate for the OmniPanel `/` membrane is **largely LANDED at presence level**: `omnipanel-shell` extension is on disk (35 files, wholesale port from `epi-app/renderer/components/OmniPanel.tsx`), `agentic-control-room/src/common/run-model.ts` defines the entire content model (`RunTreeNode`, `ToolStreamEvent`, `MediatedRunEvidencePacket`, `enforceHumanGate`, capability gates), `CrossLayoutIntent` envelope is typed, `OMNIPANEL_TABS.availableInLayouts` filter is scaffolded. Wave-C work concentrates on **(a) collapsing the legacy 13-tab manifest to the canonical 8 (27.0, 27.10)**, **(b) reframing each ported panel as its 15.2-canonical semantic (27.1-27.8)**, **(c) wiring intent-routing + session-continuity contracts (27.9, 27.11)**, **(d) extending discipline (27.12, 27.13)**. None of these are greenfield. Every tranche either reframes a landed panel, consolidates ported panels, first-builds inside the omnipanel-shell extension (not as new extension), or extends typed contracts. The OmniPanel becomes what 15.2 reframed it to be: the agentic membrane, the `/` operator made visible as UI, the Pi voice plus its dispatch genealogy plus its evidence plus its review plus its gateway plus its diagnostics — eight aspects of one operation, persistent across both layouts.

**End of matrix.**
