## 0. Ground

The canonical M1-2 architecture already establishes six Ananda families:

```text
0 Bimba
1 Pratibimba
2 Sum
3 Difference A
4 Difference B
5 Quintessence
```

and the Vortex Modulae source carries both:

```text
raw / no-digi-root arithmetic
        +
digi-root recursive residue
```

The current C body contains useful but split realizations:

```text

        +
10×10 / %10 dynamic arithmetic access
```

The implementation task is to reunify these against the canonical source while retaining their different meanings.

## 1. Three readings, one source relation

Every ordinary scalar Ananda cell must be able to expose:

```text
A. raw12
   canonical affine/no-digital-root source value

B. dr12
   true recursive digit-root reduction of raw12

C. decimal10
   explicit decimal/mod-10 aperture used by the existing runtime path
```

These are **typed projections**, not synonyms.

### True digit root

For non-negative magnitude:

```text
dr(0) = 0
dr(n) = 1 + ((n - 1) % 9), n > 0
```

Difference families require their source-defined signed/complement treatment. `Difference A` is currently represented as raw `-1` with the wholeness residue `9`; `Difference B` as raw `+1` with residue `1`. Tests must freeze the canonical source treatment rather than applying an unsigned helper blindly.

### Decimal aperture

`decimal10` is the existing mod-10 operational view. It must not be labelled digit root. The `10×10` form belongs to the decimal/arithmetic aperture of the source system and remains available even after the full 12×12 source is compiled.

The existence of the handoff is established by the M1 architecture. The **general executable mapping for every Ananda cell** remains a current research/development edge and must be derived rather than guessed.

## 6. Jankó instrument projection boundary

The Jankó keyboard belongs downstream as a controller/playable geometry for the QL musical surface, not as Ananda source authority.

Its historical six-row construction provides:

```text
two interleaved whole-tone row families
× three repeated touch-points
= six playable rows
```

and the traditional colouring exposes alternating six-note rows with `4 white : 2 black` and `3 white : 3 black` distributions. The project-level Figure is therefore especially apt for projecting the Second-Spanda `4:2` and First-Spanda `3:3` partitions on one playable field.

A future M1′ Jankó mapping may expose Ananda/Spanda state through overlays, pressure, lighting or labels, but the keyboard geometry should remain controller-neutral with respect to the numerical substrate.

## 8. Exhaustive invariants

The executable cut should test at minimum:

### Source parity

- all source rows/columns for all six raw families;
- all source rows/columns for all six DR families;
- explicit 10×10 aperture parity with the legacy runtime where that runtime is source-correct.

### Arithmetic relation

Where source-defined:

```text
Pratibimba = Bimba + 1
Sum = Bimba + Pratibimba
Difference A = Bimba - Pratibimba
Difference B = Pratibimba - Bimba
```

Quintessence is checked against its source rule/tuple, not reduced to a scalar identity merely for test convenience.

### Reduction

- `dr(0)=0`;
- positive digit-root identity over the entire raw field;
- signed/complement semantics for difference cells fixed from canonical source.

### Oscillatory relation

- `Ananda_Matrix_Op ↔ Spanda_Stage` parity;
- tick12/position6/phase state is deterministic;
- active and conjugate phases remain addressable;
- Hopf/SU(2)/720° state agrees with the same tick.

## 9. Acceptance return

A successful substrate can answer one query without register confusion:

```text
query(family, row, col, oscillatory_state)
  -> raw source value
  -> true DR residue
  -> decimal aperture value if applicable
  -> Spanda role/phase
  -> provenance
```

and can then pass that complete state into the QL musical derivation without prematurely deciding that arithmetic value, digit-root residue, decimal remainder, pitch class, harmonic ratio or controller key are the same kind of thing.

That separation is the condition for the deeper Ananda harmonics to become executable rather than merely visible in the source matrices.
