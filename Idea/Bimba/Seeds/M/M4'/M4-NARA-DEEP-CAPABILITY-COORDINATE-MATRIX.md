## 1. Recovered subsystem meaning

Nara is the **personal dialogical / lived psycho-physical threshold** at M4: the point at which the universal structures of M0–M3 become situated in a particular life and can be experienced, interpreted, acted through, remembered, transformed and reviewed without losing the distinction between universal state, personal identity, live activity and later recognition.

The older canonical spec describes M4 as a deliberately thin, relation-rich dispatch layer rather than another universal LUT-heavy knowledge system. Its distinctive role is to hold and mediate *someone's coordinates within* the universal field, not to duplicate the universal field.

Load-bearing subsystem relations recovered so far:

```text
universal / current M1-M3 context
        ↓
M4.0 identity ground
        ↓
M4.1 embodied / medicinal / temporal condition
        ↓
M4.2 divinatory / symbolic encounter
        ↓
M4.3 transformation / process
        ↕
M4.4 context / lenses / lived convergence
        ↓
M4.5 integration / recognition / return
        ↘ governed return toward M4.0
```

This is not simply a linear workflow: the canonical relation set contains multiple cross-branch relations, while all cross-M conduits are concentrated through the M4.4 context/lens field.

`#4.4.4.4` is the high-order **Personal Pratibimba convergence coordinate**, not the source of identity itself.
