# Coordinate-Derived Chromatic System

This is the canonical Epi-Logos colour-token bundle for the M' Theia shell. The JSON file uses the W3C Design Tokens Community Group draft object shape: every token carries `$value`, `$type`, `$description`, and Epi-Logos derivation metadata under `$extensions.epilogos`.

The namespace is `epilogos.colour.*` and contains eleven sub-namespaces: family, signature, flow, highlight-category, element, psyche-facet, privacy, mode-chip, readiness, status-bar, and provenance-pill.

Polarity preservation is binding: cool stays cool and warm stays warm across light/dark inversion. The `nara-light`, `nara-dark`, and `nara-glass` variants are intentionally limited to M-tier family tokens and privacy chrome tokens.
